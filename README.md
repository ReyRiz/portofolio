# Fariz Idham Ramdhani | Personal Portfolio & Engineering Showcase

A personal engineering portfolio showcasing academic, commercial, and research projects across Full-Stack Web Development, Machine Learning, Software Quality Assurance (STQA), and Digital Multimedia Production.

## Key Features

- **Cyber-Glassmorphism & Obsidian Aesthetic**: Clean, modern dark-mode aesthetic with fluid subtle ambient orbs and responsive grid overlays.
- **Interactive Web CLI Terminal**: Built-in developer terminal with custom commands (`help`, `about`, `skills`, `projects`, `exp`, `contact`, `clear`) simulating a real Unix-like shell.
- **Interactive Audio Engine**: Procedural sound synthesizer powered by the Web Audio API with frequency ramps and user-controlled mute/unmute toggles.
- **Dynamic Content Architecture**: Centralized data management (`assets/js/portfolio-data.js`) powering projects, career timelines, formal education, and certifications seamlessly.
- **Project Showcase & Drawer Modal**: Category-based filtering, instant search querying, and comprehensive modal views featuring technical challenges and solution breakdowns.
- **Vertical Video Reel Showcase**: Dedicated video production suite demonstrating 9:16 high-retention video editing and kinetic typography.

## Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom Properties & Fluid Layouts)
- **Audio**: Web Audio API (Synthesizer AudioContext)
- **Styling**: Cyber-glassmorphism, custom responsive grid, mouse spotlight illumination
- **Typography & Icons**: Font Awesome 6.4.0, Google Fonts (Inter, Outfit, JetBrains Mono)
- **Hosting**: GitHub Pages

## Site Navigation & Pages

1. **`index.html`** - Editorial split hero with 3D cutout visuals, interactive terminal, bento highlights, high-retention video showreel, featured case studies, and career timeline.
2. **`experience.html`** - Career timeline covering enterprise software engineering, video editing leadership, and UNHAS academic laboratory assistantships.
3. **`projects.html`** - Interactive project catalog with live multi-category filters, search engine, and detailed modal views.
4. **`certificates.html`** - Verified licenses, academic credentials, and university degree information.
5. **`about.html`** - Engineering philosophy, personal background story, and comprehensive technical skill matrix.
